# DevTask

DevTask is a full-stack task management platform built as a learning
project for practicing HTML, CSS, JavaScript, TypeScript, React,
Node.js, Bash automation, Docker, PostgreSQL and CI/CD.

## Technologies

- HTML
- CSS
- Tailwind CSS
- JavaScript
- TypeScript
- React
- Node.js
- Express
- PostgreSQL
- Bash
- Docker
- GitHub Actions

## Project Structure

- `frontend/` — React frontend
- `backend/` — Node.js API
- `scripts/` — Bash automation
- `experiments/` — individual concept experiments
- `docs/` — documentation
